# Mini Mad Cat local plugin

This wrapper connects Claude Code to the separately installed Mini Mad Cat desktop companion. Start the desktop app before using its MCP controls. The passive hooks send coarse lifecycle outcomes to an authenticated loopback bridge; they do not forward prompts, transcripts, tool arguments, or conversation text. The wrapper does not start a public server. Inspect the generated absolute paths and trust the hooks through the host's normal review flow. See the main bundle's installation, outcome-policy, and platform notes.
