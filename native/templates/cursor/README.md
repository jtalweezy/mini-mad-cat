# Mini Mad Cat local plugin

This wrapper connects Cursor IDE to the separately installed Mini Mad Cat desktop companion. Its MCP bridge exposes animation and weighted outcome controls. Passive hooks acknowledge session and turn events with small reactions, and observe tool failures without forwarding conversation text. Start the desktop app separately and inspect the generated paths before enabling the plugin. The companion's mouse-pointer tracking runs locally and is separate from Cursor IDE's agent tools. See the main bundle's installation, outcome-policy, and platform notes.
