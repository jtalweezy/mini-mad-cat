# Mini Mad Cat local plugin

This Claude-compatible wrapper connects Grok Build to the separately installed Mini Mad Cat desktop companion. Start the desktop app before using its MCP controls. Passive hooks send coarse lifecycle outcomes to an authenticated loopback bridge; they do not forward prompts, transcripts, tool arguments, or conversation text. This is the local Grok Build integration, not a hosted Grok Bot connector. Inspect the generated absolute paths and follow the host's hook trust flow. See the main bundle's installation and platform notes.
