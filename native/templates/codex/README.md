# Mini Mad Cat local plugin

This Agent Plugins wrapper connects local Codex to the separately installed Mini Mad Cat desktop companion. Its MCP bridge exposes animation and weighted outcome controls. Passive hooks acknowledge session and turn events with small reactions, and observe structured failures without forwarding conversation text. Start the desktop app separately and review the hooks before enabling them. Generated paths refer to the installed companion directory, so regenerate this wrapper after moving that directory. See the main bundle's installation and platform notes.
